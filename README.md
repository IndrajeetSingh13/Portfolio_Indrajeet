# Indrajeet Singh - Portfolio

A single-file static site (HTML, CSS, JavaScript). No build step.

## Run locally
Open `index.html` in a browser.

## Deploy
- Netlify: drag this folder onto https://app.netlify.com/drop
- Vercel: run `npx vercel` in this folder
- GitHub Pages: push to a repo, then Settings > Pages > deploy from the main branch

## Before publishing
Replace the placeholder projects in `index.html` with your real ones.
